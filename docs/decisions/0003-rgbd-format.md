# 0003 RGB-D とキルトの形式

## RGB-D

- 左が色、右が深度。幅は偶数。
- 深度は近いほど白い。R が上位 8bit、G が下位 8bit。
- 下端の左から、同じ長さの4区画で次を書く。
  1. RGB (80, 83, 70)
  2. 近い距離。メートルを 100 倍した 16bit を R と G に入れ、B は 170
  3. 遠い距離。同様に B は 85
  4. RGB (70, 83, 80)
- Studio が書き出すファイルは1ピクセル幅。Shot のファインダーは画面いっぱいに撮っても残るよう、横幅 1024 分の 16 の区画で同じ色を塗る。
- 読み取りは区画の長さが揃っていることで、1ピクセルと太い区画の両方を受ける。
- 上下が逆でも、上端に同じ目印があれば反転して読む。
- 許容差は各チャンネル 24。JPEG や色空間のずれ用。
- 四隅にも短い対の目印を置き、画面いっぱいでない写真から札の範囲を探す。

## キルト

- ファイル名は `元の名前_qs{列}x{行}a{縦横比}.png`。
- 縦横比は1枚の幅 ÷ 高さ。例は `photo_qs8x6a0.75.png`。
- 視点0は左下。右へ進み、上の行へ。右上が最後の視点。
- 縦長の初期値は 8x6、横長は 11x6。

## SBS

- 左半分が左端の視点、右半分が右端の視点。
