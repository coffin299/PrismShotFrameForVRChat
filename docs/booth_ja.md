# PrismShotFrame 配布文

価格は付けない。ライセンスキーも透かしも解像度制限も無い。

## 短い説明

VRChat の写真を、見る角度で奥行きが変わる立体写真にします。カメラは1〜2台です。多視点は、撮ったあと PC 上の Studio で作ります。普通の写真は AI で立体化できます。ワールドの額縁は PC と Quest の両方で使えます。

Looking Glass Portrait / Go で表示できます（※Looking Glassは Looking Glass Factory の商標です）。

## 含まれるもの

- Studio（Windows）
- Shot（PC アバター、Modular Avatar）
- Frame（ワールド、額縁3種、スライドショー、キルトと RGB-D）

## 画像と動画の素材リスト

- Studio の画面。一覧、プレビュー、書き出し。
- マウスを動かして視点が変わる短い動画。
- Shot を手に持った状態と、カードいっぱいに撮った RGB-D。
- 同じ写真を額縁に飾り、横へ移動して奥行きが見える動画。
- Quest で RGB-D の額縁を見た画面。

## 体験ワールドの構成

1. 入口に、RGB-D の平面額縁を1枚。
2. 次の部屋に、縁付きと厚み付き。キルトは PC 側だけ。
3. スライドショーを1台。
4. 説明パネルに、Shot の導入と「カードを画面いっぱいに撮る」ことを書く。
5. PC と Android は同じ Blueprint ID にする。
